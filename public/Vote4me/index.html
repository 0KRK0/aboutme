Add a map key to switch on 3D Edinburgh

The photographic city comes from Google Photorealistic 3D Tiles, which need a key. Pick one route, then put the key in public/Vote4me/config.js.

  1. Free: make a Cesium ion account at ion.cesium.com, create an access token, add https://0krk0.dev under Allowed URLs, and paste it into cesiumIonToken.
  2. Google directly: enable the Map Tiles API in a Google Cloud project with billing, restrict the key to that API and to https://0krk0.dev/*, and paste it into googleMapsKey.
